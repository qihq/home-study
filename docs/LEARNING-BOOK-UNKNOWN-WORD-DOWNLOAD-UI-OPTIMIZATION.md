# 学习本、生词本与下载页 UI 优化方案

## 1. 文档状态

- 状态：待确认，尚未开始实现
- 范围：学习本、单词识别与创建学习本、生词本生成学习本、视频下载完成与分享页
- 适配端：手机、平板、电脑
- 视觉来源：仅使用现有 Animal Island UI 素材，或从项目已注明的上游站点补充素材；不使用 AI 生成图、不自行仿画角色
- 上游来源：<https://github.com/guokaigdg/animal-island-ui>
- 授权：CC BY-NC 4.0，继续保留现有署名文件

## 2. 优化目标

1. 把当前学习本页面中过多同时展示的模块分层，用户进入页面后能立即看懂“查看学习本”和“创建学习本”是两件事。
2. 把手动录入、图片识别、文件导入拆成清晰的创建方式，避免多个上传控件和编辑区一起堆在页面上。
3. 生词生成学习本后，不只提示“已创建”，而是在生词本内持续展示生成的学习本，并可通过 Tab 切换不同学习本。
4. 保持手机、平板、电脑三端一致的功能层级，根据屏幕宽度调整排列、操作区和图片大小。
5. 解决电脑端下载完成后分享操作被页面大图干扰的问题，让完成态先突出保存和分享操作。
6. 延续当前动森小岛风格，但减少纯装饰内容对主要任务的遮挡。

## 3. 当前问题

### 3.1 学习本页面

当前页面同时展示以下内容：

- 已保存的全部学习本；
- 学习本名称；
- 粘贴单词文本框；
- 整理单词按钮；
- 拍照识别入口；
- 相册识别入口；
- 文件导入入口；
- OCR 保存提示；
- 单词逐条编辑；
- 发音进度与发音来源设置。

这些内容没有明确的任务分层。尤其在手机端，用户需要滚动很长距离才能完成一次图片识别和确认。

### 3.2 生词本页面

当前生词本可以选择生词并创建学习列表，但创建完成后只显示一条状态提示。存在以下问题：

- 看不到刚生成的学习本内容；
- 刷新后无法从生词本继续找到生成结果；
- 多次生成的学习本没有区分方式；
- 无法在生词本内确认、修改名称或进入默写；
- 后端目前给生成结果统一命名为“生词复习”，多个结果会重名；
- 生词生成的草稿使用统一学习本数据表，但缺少明确的 `unknown_items` 来源标记，草稿条目也没有被现有列表接口完整返回。

### 3.3 电脑端下载与分享

当前下载页在完成后仍保留较大的角色图片，并会在文件就绪后自动尝试打开系统分享。电脑端的主要问题是：

- 大图占据完成卡片左侧的大块区域，操作区不够突出；
- 自动弹出的分享体验与电脑浏览器习惯不一致；
- 分享取消后，用户仍要在大图旁寻找再次保存按钮；
- 页面完成态和下载中状态共用相同版式，没有根据任务阶段调整视觉优先级。

## 4. 总体信息架构

### 4.1 学习本

学习本页面使用一级 Tab：

1. `我的学习本`
2. `创建学习本`

`创建学习本` 内使用二级来源 Tab：

1. `粘贴录入`
2. `图片识别`
3. `文件导入`

默认进入 `我的学习本`。如果用户从其他页面带着“创建”意图进入，或者正在编辑某个学习本，则自动进入 `创建学习本`。

### 4.2 生词本

生词本页面使用一级 Tab：

1. `生词`
2. `生成的学习本`

`生成的学习本` 内，每一个由生词生成的学习本使用一个可横向滚动的二级 Tab。Tab 名称使用学习本名称；重名时附加创建日期或序号。

### 4.3 下载页

下载页不增加新导航层级，仍保持单任务页面，但按状态切换布局：

- 下载中：进度优先，保留小岛角色陪伴图；
- 下载完成：操作优先，缩小或隐藏大图；
- 分享中：显示轻量遮罩和明确提示，页面大图不参与视觉竞争；
- 失败或取消：恢复操作优先。

## 5. 学习本页面详细设计

### 5.1 页面头部

页面头部采用紧凑的小岛公告板样式：

- 标题：`学习本`
- 说明：`整理单词、短语和句子，创建自己的默写任务。`
- 装饰图：使用现有 `/animal-island/diy.svg` 或上游同系列素材；图片只占头部角落，不覆盖标题和按钮。

头部下方紧接一级 Tab，避免先展示大图再让用户寻找功能。

### 5.2 “我的学习本”Tab

每个学习本以卡片显示：

- 学习本名称；
- 来源标签：手动录入、图片识别、文件导入、生词生成；
- 条目数量；
- 最多 5 个条目预览；
- 发音状态摘要；
- 主操作：`开始默写`；
- 次操作：`查看/编辑`；
- 更多操作：`删除`。

发音来源的逐词设置默认收起到 `发音设置` 折叠区，不再直接铺满整张卡片。后台发音生成中时，卡片顶部显示简短进度；后台服务离线时保留全页警告。

空状态使用现有 `diy.svg` 或 `critterpedia.svg`，配文 `还没有学习本，去创建第一本吧`，并提供 `创建学习本` 按钮。

### 5.3 “创建学习本”Tab

创建流程固定为三步：

1. 选择来源；
2. 识别或整理内容；
3. 确认并保存。

页面始终显示学习本名称输入框，但一次只显示当前来源对应的控件。

#### 粘贴录入

- 显示多行文本框；
- 支持换行、逗号和分号分隔；
- 主按钮为 `整理内容`；
- 整理完成后进入确认清单。

#### 图片识别

- 手机端显示两个清楚的大按钮：`拍照识别`、`从相册选择`；
- 平板端并排显示两个按钮；
- 电脑端显示 `选择图片` 和拖放区域，不显示容易误导的“拍照”主入口；如果设备支持摄像头，仍可在次级操作中选择；
- 识别期间显示单一进度状态，不提前显示空的确认编辑器；
- 识别完成后显示识别数量、可编辑清单和 `保存为学习本`；
- 不再同时出现两次保存按钮，OCR 顶部提示只负责说明结果，最终保存统一放在清单底部的固定操作区。

#### 文件导入

- 显示支持格式：TXT、CSV、XLSX、DOCX、PDF；
- 显示单一上传/拖放区域；
- 解析完成后与图片识别共用确认清单；
- 解析警告显示在清单上方，不与全页状态混在一起。

### 5.4 确认清单

确认清单统一服务三种来源。每条内容包含：

- 正文；
- 类型：单词、短语、句子；
- 翻译；
- 删除本条按钮。

增加以下轻量操作：

- `删除空项`；
- `清除重复`；
- `全部清空`，需要二次确认。

保存操作区显示：

- `共 N 条`；
- 主按钮 `保存为学习本`；
- 编辑已有学习本时显示 `保存新版本` 和 `取消编辑`。

手机端操作区固定在底部导航上方；平板和电脑端保持在清单底部，不遮挡内容。

## 6. 生词本页面详细设计

### 6.1 “生词”Tab

顶部保留状态和类型筛选，但改为紧凑工具条：

- 状态：不认识、已掌握；
- 类型：全部、单词、短语、句子；
- 当前结果数量；
- `全选当前结果`。

条目卡片保留正文、翻译、类型、掌握状态和删除操作。选择框扩大可点击范围，点击卡片的选择区即可选中。

选中条目后出现创建栏：

- 显示 `已选 N 条`；
- 可输入学习本名称；
- 默认名称为 `生词复习 · MM/DD`；
- 主按钮 `生成学习本`；
- 次操作 `取消选择`。

创建成功后：

1. 清空已选条目；
2. 刷新生成的学习本列表；
3. 自动切换到 `生成的学习本`；
4. 自动激活刚生成的学习本 Tab；
5. 显示一次成功提示。

### 6.2 “生成的学习本”Tab

该区域只展示来源为 `unknown_items` 的学习本，不混入手动、图片或文件创建的学习本。

二级 Tab 规则：

- 按创建时间倒序；
- 默认激活最新一本；
- 手机和平板可横向滑动；
- 电脑端空间足够时自动换行；
- Tab 显示名称和条目数；
- 不依赖浏览器本地状态，刷新后仍能从后端恢复。

当前学习本面板显示：

- 名称和创建时间；
- 草稿/已确认状态；
- 条目总数；
- 完整条目列表，包含正文、类型和翻译；
- `确认并开始默写`；
- `修改名称`；
- `删除学习本`。

由生词生成时先保持草稿状态，让家长确认内容。点击 `确认并开始默写` 后调用确认接口，生成正式版本并进入默写。这样避免选择错误后直接进入不可修改的正式学习本。

### 6.3 数据与接口调整

为支持刷新后持续展示，需要补充以下后端行为：

1. 生词生成学习本时写入 `source_type = "unknown_items"`；
2. 创建接口接收学习本名称，未提供时由服务器生成带日期的默认名称；
3. 列表接口支持按 `source_type` 筛选；
4. 草稿学习本从版本 `0` 返回条目，不能因为 `current_version` 为空而返回空数组；
5. 列表结果返回 `created_at`、状态、条目、版本 ID和条目数量；
6. 确认草稿后返回正式版本 ID，供前端直接开始默写；
7. 删除沿用归档策略，避免破坏历史默写记录。

本次继续复用统一的学习本、版本和学习条目数据表，不新建一套重复模型。

## 7. 下载页详细设计

### 7.1 电脑端

电脑端不在下载完成后自动打开系统分享面板。文件准备完成后：

- 页面切换为紧凑完成态；
- 角色大图缩小为不超过 72px 的角标，或在宽度不足时完全隐藏；
- 操作区移动到卡片中心并置顶；
- 主按钮按能力显示 `保存 MP4` 或 `分享视频`；
- 次按钮显示 `返回视频库`、`返回主页`；
- 用户点击 `分享视频` 后才调用系统分享，保证来自明确的用户手势；
- 分享调用期间显示覆盖在下载卡片上的半透明轻量遮罩，`z-index` 高于页面装饰图，提示 `请在系统窗口中完成分享`；
- 分享取消后立即恢复按钮，不改变文件就绪状态。

这样即使浏览器的分享窗口没有完全覆盖网页，背景也只保留弱化后的操作卡，不会被大角色图干扰。

### 7.2 手机与平板

- 保留现有“下载完成后尝试唤起系统保存/分享”的快捷流程；
- 如果浏览器要求用户手势或用户取消，则回到完成态并突出 `保存到照片`；
- 分享中同样弱化或隐藏角色图；
- 平板横屏使用左右布局，但完成态操作区至少占 60% 宽度；
- 手机端按钮纵向排列并占满可用宽度。

### 7.3 设备判断

不单独依赖 User-Agent。优先结合以下能力判断：

- `navigator.share` 与 `navigator.canShare({ files })`；
- `matchMedia('(hover: hover) and (pointer: fine)')` 判断典型电脑输入；
- `navigator.maxTouchPoints` 辅助识别触屏平板。

无论判断结果如何，都必须保留手动 MP4 下载回退，不允许应用窗口被视频地址替换。

## 8. 三端响应式规则

沿用项目现有断点：

| 终端 | 宽度 | 主要布局 |
| --- | --- | --- |
| 手机 | `< 700px` | 单列；Tab 横向滚动；底部主操作固定在底栏上方；按钮尽量全宽 |
| 平板 | `700px - 1179px` | 双列卡片；来源按钮并排；确认清单保持单列以便编辑 |
| 电脑 | `>= 1180px` | 左侧现有导航；内容区双栏或三栏；完成态操作优先并缩小装饰图 |

通用规则：

- 页面不得出现横向溢出；
- Tab 最小触控高度 44px；
- 手机底部固定操作不得覆盖最后一条内容；
- 键盘聚焦状态清晰；
- 支持 `prefers-reduced-motion`；
- 状态提示使用 `role="status"`，错误使用 `role="alert"`；
- Tab 使用 `role="tablist"`、`role="tab"`、`role="tabpanel"`，支持方向键切换。

## 9. Animal Island 视觉规范

### 9.1 可使用内容

- 现有 `/frontend/public/animal-island/` 中的角色、叶子、菜单背景、DIY、设计、购物、相机等素材；
- 实现时如确有缺图，只从已署名的 Animal Island UI 上游项目补充；
- 上游新增素材需记录到 `ATTRIBUTION.txt`，并保留原始许可信息。

### 9.2 不使用内容

- AI 生成的动森仿制图；
- 自行描摹 Nintendo 角色；
- 来源不明的网络图片；
- 用 Emoji 代替已有图标；
- 与现有素材风格不一致的第三方图标包。

### 9.3 页面风格

- 主色继续使用青绿色、奶油白、浅黄色；
- 卡片使用圆角、轻描边和低强度阴影；
- 叶子纹理和角色图只作为陪伴元素，不覆盖输入框、Tab 或主按钮；
- 一个任务区最多保留一个主要角色图，避免“动森元素越多越好”造成新的混乱；
- 文本、输入和按钮仍由 HTML/CSS 实现，图片只负责装饰和图标。

## 10. 状态与异常处理

### 学习本

- 列表加载失败：显示重试，不影响进入创建 Tab；
- OCR 失败：保留已输入的学习本名称，可重新选图或切换来源；
- 文件解析失败：显示具体格式提示；
- 保存失败：保留确认清单，不能清空用户内容；
- 发音服务离线：学习本仍可保存，明确说明发音稍后生成。

### 生词本

- 创建失败：保留选择和名称；
- 创建成功但列表刷新失败：保留返回的学习本 ID，并提供重试；
- 无生成结果：显示空状态和“去选择生词”；
- 草稿确认失败：留在当前学习本 Tab，不进入默写；
- 删除当前学习本后：激活下一本；没有下一本时显示空状态。

### 下载页

- 下载失败：显示重试和返回视频库；
- 分享失败或取消：保留文件和所有手动操作；
- 浏览器不支持文件分享：只显示 `保存 MP4`；
- 离开页面：取消未完成请求并释放 Blob URL；
- 系统分享期间：禁止重复点击分享按钮。

## 11. 测试范围

### 前端自动化测试

- 学习本一级 Tab 默认只展示我的学习本，不同时铺开创建表单；
- 创建来源 Tab 一次只显示对应输入控件；
- 图片识别后进入统一确认清单，页面只有一个最终保存入口；
- 编辑已有学习本自动进入创建/编辑 Tab；
- 生词创建成功后自动切换到生成结果并激活新 Tab；
- 多个生成学习本可以通过 Tab 切换，刷新数据后仍存在；
- 草稿确认成功后使用返回的版本 ID 进入默写；
- 电脑端下载完成不自动调用分享；
- 电脑端点击分享后进入分享中紧凑状态；
- 触屏设备仍保留快捷分享，取消后可再次保存；
- 三类页面的 Tab、状态和按钮具备正确的无障碍语义。

### 后端自动化测试

- 从生词创建的学习本记录 `unknown_items` 来源；
- 自定义名称和默认名称都正确保存；
- 草稿列表返回版本 0 的完整条目；
- 来源筛选不会混入其他学习本；
- 确认草稿后返回正式版本并保留条目类型与翻译；
- 删除使用归档，不破坏已有默写历史。

### 三端手动验收

- 手机：iPhone 尺寸，完成图片识别、编辑、保存；选择生词生成两本学习本并切换；下载视频并保存到照片；
- 平板：iPad 竖屏和横屏，检查 Tab、双列卡片和底部操作不重叠；
- 电脑：至少 1366×768，检查学习本列表与创建区层级；下载完成后大图不遮挡或抢占分享操作；
- 三端均检查 200% 文本缩放、键盘 Tab 导航和无横向滚动条。

## 12. 验收标准

满足以下条件才算完成：

1. 学习本页进入时不再同时展示已保存列表、三种导入控件和确认清单。
2. 用户可在不超过两次 Tab 选择后进入任一创建方式。
3. OCR 成功后只有一个明确的最终保存按钮。
4. 生词生成学习本后立即出现可见结果，刷新页面后结果仍可找到。
5. 多个生词学习本可通过 Tab 独立切换，不互相覆盖。
6. 生词学习本确认后可直接开始默写。
7. 手机、平板、电脑均无内容遮挡和横向溢出。
8. 电脑端下载完成后不自动弹分享；大图不再占据主要操作区域。
9. 分享取消不会丢失已下载文件，用户可以再次分享或保存 MP4。
